## 🧠 NeuroSafe AI
AI that doesn’t just see — it understands and acts
# 🚀 Overview

NeuroSafe AI is an intelligent safety system that combines Computer Vision with Neuro-Symbolic AI to detect, analyze, and respond to potentially dangerous real-world situations.

Unlike traditional CCTV systems that only record footage, NeuroSafe AI transforms surveillance into a proactive safety solution by identifying risks and triggering real-time alerts.

# 💡 Problem Statement

Current surveillance systems:

Only monitor and record
Lack contextual understanding
Cannot prevent accidents in real-time

Goal: Build an AI system that not only detects objects but also understands situations and acts immediately.

# 🧩 Solution

NeuroSafe AI integrates with CCTV cameras and applies:

Object Detection (Vision Layer)
Contextual Reasoning (Neuro-Symbolic Layer)
Alert System (Action Layer)

This allows the system to move from:

**“What is happening?” → “Is it dangerous?” → “Take action”**

# ⚙️ Key Features
🔍 Real-time object detection
🧠 Context-aware decision making
🚨 Instant alerts (beep sound + notification)
📹 CCTV integration capability
⚡ Fast and scalable architecture
🎯 Use Cases
👶 Child handling dangerous objects (e.g., knife)
👴 Elderly fall detection with no movement
⚠️ Unusual or hazardous activities in monitored areas

# 🛠️ Tech Stack
Python
OpenCV
YOLO (Ultralytics)
Neuro-Symbolic AI concepts
Threading / Real-time processing

# 🧪 How It Works
Capture live video feed from CCTV
Detect objects using YOLO
Apply symbolic rules to analyze context
Identify risky scenarios
Trigger alert (sound + notification)
📊 Project Architecture
Input (CCTV Feed)
        ↓
Object Detection (YOLO)
        ↓
Context Analysis (Neuro-Symbolic Layer)
        ↓
Decision Engine
        ↓
Alert System (Beep + Notification)
